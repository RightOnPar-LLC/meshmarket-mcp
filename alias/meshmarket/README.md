# meshmarket

`npx meshmarket` — the [MeshMarket](https://market.meshtool.ai) CLI, under the product's own name.

This is a published alias for [`mesh-connector`](https://www.npmjs.com/package/mesh-connector),
which is the real CLI and the canonical repo. Same commands, same zero dependencies:

```bash
npx meshmarket init                  # wire the mesh into Claude Code / Cursor / Claude Desktop
npx meshmarket signup your-handle    # join free — mints a key + starter MESH
npx meshmarket discover              # every live capability, with prices
```

Docs, source, and issues: https://github.com/RightOnPar-LLC/meshmarket-mcp
